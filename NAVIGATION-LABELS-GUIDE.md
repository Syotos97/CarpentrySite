# Navigation Labels Guide

The main navigation labels are managed in Shopify Admin, not in this theme repository.

Use these labels for a tighter carpentry-specific header menu:

1. Home
2. Projects
3. Shop
4. Custom Orders
5. Shipping
6. Reviews
7. Quote Request
8. Contact

Recommended destinations:

1. Home -> `/`
2. Projects -> a portfolio page or homepage anchor section
3. Shop -> `shopify://collections/all`
4. Custom Orders -> `/pages/custom-orders`
5. Shipping -> `/pages/shipping`
6. Reviews -> `/pages/reviews`
7. Quote Request -> `/pages/quote-request`
8. Contact -> `/pages/contact`

To update these labels in Shopify Admin:

1. Open Online Store > Navigation.
2. Open `Main menu`.
3. Rename existing items or add the items above.
4. Point each item to the matching page, collection, or URL.
5. Save the menu.
